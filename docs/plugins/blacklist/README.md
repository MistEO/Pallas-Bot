# 牛牛黑名单 `blacklist`

维护全局拉黑与本群屏蔽名单。需要拦截某用户 / 某群，或解除屏蔽时用本插件。

**类型**：本体 core（默认加载）

## 安装

默认加载，无需单独安装。

## 用法

| 命令 / 触发 | 场景 | 说明 |
| --- | --- | --- |
| `牛牛拉黑` / `牛牛屏蔽` + QQ 或 `@` | 私聊 | 全局用户拉黑 |
| 同上 | 群内 | 本群用户屏蔽 |
| `牛牛拉黑群` / `牛牛屏蔽群` + 群号 | 私聊 | 拉黑指定群 |
| `牛牛解禁` / `牛牛取消拉黑` + 目标 | 私聊 / 群内 | 解除用户拉黑或屏蔽 |
| `牛牛解禁群` / `牛牛取消拉黑群` | 私聊 / 群内 | 解除群拉黑 |
| `添加屏蔽词` + 词 | 群内 | 在本群追加一个消息屏蔽词（可含空格） |
| `删除屏蔽词` + 词 | 群内 | 移除本群的一个追加屏蔽词 |
| `查看屏蔽词` [页码] | 群内 | 分页查看本群追加的屏蔽词（每页 20 条） |
| `添加屏蔽词` + 词 | 私聊 | 为当前 Bot 追加一个屏蔽词（作用于该 Bot 所有群与私聊） |
| `删除屏蔽词` + 词 | 私聊 | 移除当前 Bot 的一个追加屏蔽词 |
| `查看屏蔽词` [页码] | 私聊 | 分页查看当前 Bot 追加的屏蔽词（每页 20 条） |

精确命令与「何人可用」以群内 **牛牛帮助** 为准。私聊偏全局，群内偏当前群。

### 群追加屏蔽词

`添加屏蔽词` / `删除屏蔽词` / `查看屏蔽词` 在群内只改当前群的 `message_scrub_extra`：

- 与全局词库**叠加**：全局关键词、词表文件与内置下流词表照常生效，群词只做追加。
- **只作用于本群**，不提供关闭或覆盖全局；私聊不触发。
- 词可含空格（整段余下文本视作一个词）；最多 200 词、每词 64 字符，strip、去空、大小写不敏感去重。
- 全局总开关 `PALLAS_MESSAGE_SCRUB_ENABLED=false` 时，群追加词同样**休眠**（仍可增删查看，但不拦截）。
- 命中仅做入站拦截，**不撤回**已发送消息。
- 命令读写按群加锁串行，但**仅同进程**：多 worker / 多部署与 WebUI 整数组保存仍是后写覆盖（LWW），非分片并发安全。

### Bot 追加屏蔽词

私聊中同样的 `添加屏蔽词` / `删除屏蔽词` / `查看屏蔽词` 命令管理当前 Bot 的 `message_scrub_extra`：

- **按 Bot 隔离**：只作用于该 Bot 的所有群与私聊，其他 Bot 不受影响；Bot id 与群 id 相同也不串。
- 与全局词库、各群词**叠加**；移除 Bot 词不会削弱全局或群词。
- 仅**当前 Bot 绑定号主**可在私聊管理：其它 Bot 号主、未绑定超管、群管、ACL 放行与「命令权限」的 everyone 覆盖都不能越过；群临时会话（sub_type=group）不能管理。命令读写前复核该硬条件，失败即拒绝。
- 词可含空格；最多 200 词、每词 64 字符，strip、去空、大小写不敏感去重。
- 全局总开关 `PALLAS_MESSAGE_SCRUB_ENABLED=false` 时同样**休眠**（仍可增删查看，但不拦截）。
- 命中仅做入站拦截，**不撤回**已发送消息。
- 命令读写按 Bot 加锁串行，但**仅同进程**：多 worker / 多部署与 WebUI 整数组保存仍是后写覆盖（LWW），非分片并发安全。

## 命令权限（代码默认）

| 命令 ID | 默认等级 |
| --- | --- |
| `blacklist.add` | 群管或号主 |
| `blacklist.remove` | 群管或号主 |
| `blacklist.scrub_add` | 群管/群主 |
| `blacklist.scrub_remove` | 群管/群主 |
| `blacklist.scrub_list` | 群管/群主 |
| `blacklist.bot_scrub_add` | 号主 |
| `blacklist.bot_scrub_remove` | 号主 |
| `blacklist.bot_scrub_list` | 号主 |

实际生效等级以控制台「命令权限」为准。面向用户的 usage 不要写死角色名。`blacklist.bot_scrub_*` 除命令权限外还有「当前 Bot 号主」硬条件，控制台把等级放宽到 everyone 也不会让非号主获得管理权。

## 配置

无独立插件配置页；当前名单保存在用户 / 群配置中，操作历史保存在 `blacklist_audit` 表 / 集合。
数据库页「存储」中可只读查看历史；本群开关见帮助图。

## 排障

| 现象 | 处理 |
| --- | --- |
| 仍然收到消息 | 分清全局拉黑、本群屏蔽与群拉黑，作用范围不同 |
| 好友申请没被拦 | 只有全局用户拉黑会直接拒绝好友申请 |
